# Interface languages

[English guide](../README.md) · [한국어 시작 안내](../README.ko.md)

The local catalog supports English (`en`) and Korean (`ko`), without external
translation services. Only bridge-owned notices and controls are translated.
Prompts, AI answers, option text, model identifiers, code and tool diagnostics
remain unchanged. Terminal setup/doctor output and advanced operator reports
retain their existing wording. The Korean guide covers installation and core use.

## Selection

Use `/language en`, `/language ko`, or `/language` in the configured chat.
Selection persists in `claude-bridge-language.json` under the bridge state directory.
The file has private permissions. Each engine uses its own file and environment
prefix, so selecting a language in one bridge does not change the others.

Precedence: saved selection → `CLB_LANGUAGE` → `TAB_LANGUAGE` → install default.
Public exports default to English; internal source installs retain Korean.
Regional environment values such as `ko-KR` are normalized. Unsupported commands
show usage without changing the selection. Unreadable state falls back to the
configured default; failed writes leave the previous in-memory selection intact.
Existing cards are not proactively edited when the language changes; new renders
use the current selection. Callback values and submission semantics do not change.

## Verification paths

Prerequisite: one configured, allowlisted Telegram chat. Automated tests use fake
Telegram/engine clients and temporary state. A live send or restart requires the
operator's authorization and a separate receipt.

| Operation | Expected result | Evidence |
| --- | --- | --- |
| `/language en`, `/language ko`, restart | Selection persists; reply uses selected language | `tests/test_bridge_engine_i18n.py` and shared catalog tests |
| `/language ja` | Usage response; selection unchanged | Language command boundary test |
| Same text from another chat | Ignored by existing chat allowlist | Allowlist test |
| Language command during a running task | No engine input, job queue entry or session reset | No-injection test |
| Approval or choice card | Localized instructions; original options and callback values | Rendering tests |
| AI answer matches an owned notice | Answer is relayed without catalog substitution | Raw-answer regression |
| Public export | Includes locale helper, Korean guide and tests | Export self-test and test manifest |

These local tests do not by themselves prove a live Telegram round trip.
Operational deployment additionally checks installed hashes, fresh bridge PIDs,
retained engine sessions and healthy polling.
